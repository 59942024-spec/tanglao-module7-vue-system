# Enchang Ordering & Menu Management System
**Student Name:** Angelica Tanglao
**Section:** Software Engineering 1

## 📋 System Description
A complete food ordering and menu management system with customer registration, order tracking, earnings calculation, dark/light mode, and localStorage data persistence. Built with Vue 3 + Tailwind CSS.

## ✅ Implemented Features
- Dashboard with real-time statistics
- Menu Management (Add, Edit, Delete)
- Customer Registration & Ordering
- Order Status Tracking
- Mark Orders as Done / Served
- Search & Filter
- Form Validation
- Dark / Light Theme
- localStorage Auto-Save
- Fully Responsive Design

## 🛠️ Technologies Used
- Vue 3 (Composition API / `<script setup>`)
- Tailwind CSS
- JavaScript
- localStorage API
